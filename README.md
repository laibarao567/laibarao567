## 🚀 Featured Project — Hand2Voice

**A real-time gesture translator bridging communication for Pakistan's deaf and mute community.**

| Component | Details |
|---|---|
| **Sign Recognition** | ViT-Base-Patch16-224 trained on UAlpha40 (36 Urdu sign alphabet classes) — 99.67% test accuracy |
| **Hand Detection** | MediaPipe HandLandmarker, TFLite for on-device inference |
| **Offline Speech-to-Text** | Whisper.cpp via JNI/NDK for on-device Urdu transcription |
| **Voice Output** | Three-layer fallback — cached sentences → Fish Audio API → Android TTS — with local MP3 caching |
| **Performance** | Gesture recognition <2s/frame · STT in 3–5s · voice output <4s |

**Repository:** [Hand2Voice-demo →](https://github.com/laibarao567/Hand2Voice-demo)
