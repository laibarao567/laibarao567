### 🚀 Featured Project — Hand2Voice

**Hand2Voice** is a real-time gesture translator built as my Final Year Project, designed to bridge communication for Pakistan's deaf and mute community.

- 🤟 **Sign Recognition** — ViT-Base-Patch16-224 model trained on the UAlpha40 dataset (36 Urdu sign alphabet classes), achieving **99.67% test accuracy**
- 🎙️ **Offline Speech-to-Text** — Whisper.cpp integrated via JNI/NDK for on-device Urdu transcription
- 🗣️ **Voice Cloning** — Three-layer fallback system (pre-cached sentences → Fish Audio API → Android TTS) with local MP3 caching
- ⚡ **Fast & Reliable** — Gesture recognition under 2s/frame, STT in 3-5s, voice output under 4s
- 📄 Research on this system has been developed into review and implementation papers, with the review paper under review at the *British Journal of Educational Technology* (Wiley)

🔗 [Hand2Voice-demo Repository](https://github.com/laibarao567/Hand2Voice-demo)
